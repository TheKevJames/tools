Deterministic SSH Key Generator
===============================

Generate an ssh key deterministically from a password. Inspired by
`passphrase2gpg`_.

Note that you should generally have a unique ssh key per host, so long-term or
consistent/repeatable key generation is an anti-pattern. SSH keys should not be
backed up, and it is important to be able to eg. revoke them in case of
theft/etc. DO NOT USE THE KEYS GENERATED BY THIS SCRIPT FOR DAILY USE.

However, as described in @skeeto's repo, a key like this can be very useful for
emergency situations: when setting up a system you normally access via ssh, you
can use this script to preload an emergency ssh key:

.. code-block:: shell

    uv run https://raw.githubusercontent.com/TheKevJames/tools/refs/heads/master/deterministic-ssh/cli.py >> ~/.ssh/authorized_keys

Or, if the target machine doesn't have python/uv/etc:

.. code-block:: shell

    uv run https://raw.githubusercontent.com/TheKevJames/tools/refs/heads/master/deterministic-ssh/cli.py > ~/.ssh/emergency.pub
    # copy emergency.pub to the relevant machine(s)

Then, in case of emergency, you can temporarily load the same key into your
ssh-agent to regain access to the box:

.. code-block:: shell

    uv run https://raw.githubusercontent.com/TheKevJames/tools/refs/heads/master/deterministic-ssh/cli.py --private | ssh-add -
    ssh-copy-id -i ~/.ssh/id_ed25519 user@host
    ssh-add -D

.. _passphrase2pgp: https://github.com/skeeto/passphrase2pgp/tree/master#openssh-format
